# Best README Template Skill

When creating or formatting repository README files, follow the **Best-README-Template** standard structure:

1. **Header & Shields**: Badges for Stars, Forks, Issues, License, and Build status.
2. **Project Logo & Title**: Centered title, description, and links to Live Demo / Bug Reports.
3. **Collapsible Table of Contents**: `<details>` tag with `<summary>Table of Contents</summary>`.
4. **About The Project**: Screenshot / hero image banner, product overview, and "Built With" technology badges (React, Vite, TypeScript, Tailwind/CSS, Lucide).
5. **Getting Started**:
   - Prerequisites
   - Installation & Setup steps
6. **Usage & Features**: Detailed breakdown of key capabilities and workflows.
7. **Roadmap & Ideas**: Future planned features with checkbox tracking (`- [x]`, `- [ ]`).
8. **Contributing & License**: Guidelines for community PRs and open-source license.
9. **Contact & Acknowledgments**: Social handles and design credits.
